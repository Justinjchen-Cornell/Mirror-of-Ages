# data/ — 语料说明

本目录包含：
- `kernels.json` — 28 个场景内核（检索词表 + 相关案例）
- `quotes.json` — 73 条引文登记（卷次/篇名 + 行号 + 引文）
- `zztj_index.json` / `shiji_index.json` — 卷/篇 → 行号索引（基于构建时的语料版本）

## 为什么没有全文？

`zztj.txt`（《资治通鉴》294 卷，约 24MB）与 `shiji.txt`（《史记》白话全译，约 2.5MB）**未随仓库分发**，原因：
1. **版权**：古文原文属公有领域，但底本采用的现代白话译文版权归相应出版方；
2. **体积**：单文件 24MB，不适合常规 Git 仓库。

## 如何启用全文检索

1. 自备《资治通鉴》全文（含 `资治通鉴第X卷（回目录）` 形式的卷首标记）放入本目录，命名为 `zztj.txt`（UTF-8）；
2. 自备《史记》全译文本命名为 `shiji.txt`（UTF-8）；
3. 直接使用：`python tools/retrieve.py 关键词`。

> 注：若你使用的版本与构建索引时的行号不同，`quotes.json` 与 `*_index.json` 中的行号会失配，但**关键词检索不受影响**（检索按文本匹配）；归属显示可能为 `?`，可自行重建索引。
