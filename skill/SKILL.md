# 通鉴抉择推演 · 古籍案例库

> 数据底座：《资治通鉴》294卷（中华书局点校本+白话今译；电子书存卷 288 卷，缺失卷次见数据表标注）+《史记》白话全译本。
> 案例库：44 张已拆解案例卡（cases/F01-F12）+ 28 个场景内核（data/kernels.json）+ 73 条引文登记（data/quotes.json，可直接核验）。
> 工作语言：中文。所有历史引用必须落到"卷次/篇名+行号"可查。

## 使用场景

用户说"我该不该……"「帮我推演」「以史为鉴看看这个处境」「找个历史案例」时启用。适用于：职业去留/进退时机、合伙与关系、谈判博弈、被诬与名誉、改革推动、接班传承、危机应对、人际恩怨。

## 推演流程（7 步，必须按序执行）

**① 接题（补信息）**：若用户情境信息不足，先补问（不超过 5 问）：处境一句话｜涉及的关键人物关系｜硬约束（时间/钱/身份）｜最坏结果能承受吗｜有没有时间窗口。

**② 提炼场景内核**（去时代化、去身份化）：把具体情境抽象为结构性内核，如：
- "功劳太大，上级开始不安" → `功高主疑`
- "两个朋友合伙做生意，一个觉得另一个不救他" → `合伙人反目` + `人情冷暖`
- "要不要在僵局里先低头" → `示弱脱身`
读 `data/kernels.json` 选定 1-3 个内核（28 个内核的清单可 `python tools/retrieve.py --list-kernels` 查看）。

**③ 检索历史案例（两级检索，缺一不可）**：
1. **精选案例**：读 `cases/_index.json`，按内核找到案例 id → 打开对应 `cases/F0X-*.md` 读取完整案例卡（1-3 个最相似）；
2. **全文库扩展检索**：`python tools/retrieve.py --kernel <内核名>` 或自定义关键词 `python tools/retrieve.py 关键词1 关键词2`——在 294 卷+史记全文中补充检索 2-3 个新案例（优先案例库未收录者），命中结果自带卷次/篇名归属；
3. 引文核验：案例卡的引文可在 `data/quotes.json` 或全文库中复核；新检索到的引文注明卷次/篇名+行号。

**④ 案例拆解**（每个案例按统一卡片输出）：
```
【案例名｜内核】出处：《资治通鉴》卷X·XX纪N（事件年份）
· 情境：
· 当时的选项：A / B / C（含他放弃的选项——这是最有价值的部分）
· 判断与推理：当事人当时怎么想的（区分"判断对错"与"结果好坏"）
· 结果：
· 显性代价：（钱、命、职位等可直接观测的损失）
· 隐性代价：（名声、结构、心理、后代的长期影响）
· 规律启发：（可迁移的 1-2 句）
· 风险提醒：（失效条件：「若……则此规律失效」+ 反例）
· 原文：「原文引文」（卷次/篇名）
```

**⑤ 古今映射（防生搬硬套）**：列 3-5 条"同构点 vs 不可迁移点"。固定检查：法治环境（生死赏罚 vs 契约规则）、信息条件（驿马 vs 即时通讯）、暴力门槛（族诛 vs 商誉）、退出成本、社会网络（宗族乡党 vs 陌生人协作）。

**⑥ 规律启发（2-4 条）**：跨案例归纳，每条注明"依据案例（卷次）"。避免口号化，必须能被执行。

**⑦ 风险提醒（每条建议的必要组件）**：失效条件（若……则……）｜幸存者偏差声明（同类失败者的记录往往不存在）｜反向案例（如有，如 F08 檀道济）｜不确定度（史料的夸张成分）。

## 输出模板（标准报告）

```markdown
# 抉择推演：<一句话问题>

## 0. 你的处境（内核提炼）
<原始情境摘要> → 场景内核：<内核1>、<内核2>

## 1. 历史镜鉴（N 例）
### 案例一 <名>……（按 ④ 的卡片格式）

## 2. 结构对照表
| 维度 | 历史场景 | 你的处境 | 可迁移性 |
|------|----------|----------|----------|
| 权力/利益结构 | | | 高/中/低 |
| 信息条件 | | | |
| 退出成本 | | | |

## 3. 规律启发
1. ……（依据：案例X）

## 4. 风险提醒
- ⚠️ ……（失效条件：若……则失效）

## 5. 可选行动提示（非决策替代）
<只给"决策框架/自查问题/下一步动作"，不替用户拍板>
```

## 质量闸门（红线，输出前自查）

1. 每个历史案例 ≥1 条核实过的原文引文 + 卷次/篇名；无出处的"历史故事"一律不用。
2. 显性代价与隐性代价必须分开列——只写"他后来死了"不算拆解。
3. "判断"与"结果"分开评判：判断对的可能输（幸存者偏差），判断错的可能赢。
4. 风险提醒必含失效条件，禁止"历史证明……"式宿命断言。
5. 检索不到相似案例时，诚实说"两部史书中未见高相似度案例"，再用相邻内核降级检索。
6. 不替用户做决定；不输出占卜/命运式结论。

## 边界声明

- 历史案例是"思维脚手架"，不是答案；时代差异在流程第⑤步强制标注。
- 两部史书均为"胜者/文人叙事"的剪辑版——统计样本天然偏向"被记载的成功与教训"。
- 涉及法律、投资、医疗等专业决策时，本技能只提供思考框架，专业问题请咨询持牌专业人士。
- 会话成果建议沉淀：结论卡写入 vault `00.会话沉淀/`，投资相关并入 `08.投资决策框架/`（如用户环境存在该结构）。
