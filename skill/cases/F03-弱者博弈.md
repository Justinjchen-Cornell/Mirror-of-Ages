# F03 弱者博弈：以小博大与破局智慧
> 场景内核：弱者博弈｜谈判｜绝境反击
> 适用情境：资源不对称谈判、借势破局、被强者欺压时的选择

## 案例1 蔺相如：弱者的谈判锚点与对手成本
- **出处**：《资治通鉴》卷四·周纪四（前283完璧；此后将相和）｜quotes.json: linxiangru, linxiangru_fj
- **情境**：赵得和氏璧，秦提出"以十五城易璧"。谁都知道秦大概率不会给城；但拒绝又给秦开战借口。赵王两难。
- **当时的选项**：（A）不给（秦得口实）（B）给（璧财两空）（C）派人携璧试探性谈判（选了C）。蔺相如的谈判设计：先划清"理亏"归属——「秦以城求璧而王不许，曲在我矣。我与之璧而秦不与我城，则曲在秦」——无论谈成谈不成，责任都留给对方。
- **判断与推理**：他没有幻想"说服秦王"，而是计算"秦王的成本函数"：为一块玉杀来使、背弃承诺，会毁掉秦的信用资产。于是设计"以诈绐秦王"——取回璧、派人怀璧归赵、自己留下待命。赌的是：秦王杀他不值。
- **结果**：完璧归赵，秦王"以为贤而弗诛，礼而归之"。之后廉颇不服，他选择回避退让（"先国家之急而后私雠也"），换来「肉袒负荆至门谢罪，遂为刎颈之交」——将相和的赵国内部稳定数年。
- **显性代价**：蔺相如个人两次危在秦廷（以命博信用）；对廉颇的退让让他在朝堂上短期"丢了面子"。
- **隐性代价**：以诈术谈判有复用风险——不是每个对手都像秦王一样在意长期信用；此案成功含"秦王之贤"这个未明说的变量。
- **规律启发**：弱者谈判三件套——①先定义是非（争夺"理"的归属）；②找到对手的长期成本（信用、名声、战争成本）；③用自己的"无所谓"换对方的"有所谓"。
- **风险提醒**：此案含幸存者偏差——历史上很多"完璧归赵"式赌命直接赌输了。若对手是不在乎信用的暴力方（如乱世军阀），蔺相如的方案会立刻失效；判断对手类型是前提。
- **原文**：「臣愿奉璧而往；使秦城不入，臣请完璧而归之！」「相如乃以诈绐秦王，复取璧，遣从者怀之，间行归赵，而以身待命于秦。」（卷四）

## 案例2 毛遂：三年不被看见的人如何一次翻身
- **出处**：《资治通鉴》卷五·周纪五（前258，邯郸之围）｜quotes.json: maosui
- **情境**：秦围邯郸，赵派平原君赴楚求救，要挑20名门客同往，只挑出19人。毛遂在门下三年，无一人称道。
- **当时的选项**：继续等（大概率永远等不到）；主动自我举荐（选了自荐，直接顶撞式表达）。平原君当场质疑："贤士处世，譬如锥处囊中，其末立见。先生在我门下三年，无人提起——先生不行，请留。"毛遂的回答是全场关键：「臣乃今日请处囊中耳」——您一直没把我放进囊里，今天放进去试试。
- **判断与推理**：毛遂的推理：机会是分配的，不是等待的；表述上不辩解自己"有才"，而是把责任推回给结构（你没给我场面）。到楚国后谈判僵局，他按剑上前、以"今十步之内，王不得恃楚国之众"的物理事实＋楚国的耻辱记忆（白起拔鄢郢、烧夷陵）完成施压，促成结盟。
- **结果**：楚王歃血定盟，邯郸得救。平原君叹："毛先生以三寸之舌，强于百万之师"，奉为上客。
- **显性代价**：当众被质疑、丢面子的风险（若失败将彻底被冷藏）；按剑犯上的风险。
- **隐性代价**：自荐者的长期成本——被记住的是"要过机会"，此后表现容错率更低。
- **规律启发**：任何"锥处囊中"体系里，光有本事不够，需要一次"请处囊中"的主动申请；申请的表达方式很关键：不证明"我很强"（无证据），而是指出"结构没给我样本"。
- **风险提醒**：毛遂是幸存者样本，"自荐—成功"之间还有大量"自荐—失败"的匿名案例。别忽略前置条件：他确实做了功课（楚国的历史与现场局势），自荐只是放大器，不是真空中的能力。
- **原文**：「毛遂自荐于平原君。平原君曰：“夫贤士之处世也，譬若锥之处囊中，其末立见……”毛遂曰：“臣乃今日请处囊中耳。”」（卷五）

## 案例3 孙膑与庞涓：同门相残与"围魏救赵"
- **出处**：《史记·孙子吴起列传》（白话译本）｜quotes.json: s_sunbin_du, s_sunbin_ml, s_sunbin_si
- **情境**：孙膑与庞涓同门学兵法。庞涓先仕魏，"自己认为才能不及孙膑"，暗中召他来魏，随后「假借罪名施刑断去孙膑的双足并给他脸上刺字」——肢体与人格双重销毁。
- **当时的选项**：孙膑在受刑后——（A）认命（B）装疯卖傻保命、伺机接触外国使节（选了B：暗中会见齐使，被秘密载回齐国）。
- **判断与推理**：孙膑对局势的阅读：在敌人的地盘里，活下去的唯一依托是"显得毫无威胁"（此前有装疯情节）；到了齐国后，他不急于复仇，而是先作为军事顾问积累信用（赛马论、围魏救赵），用两次大胜（桂陵、马陵）让庞涓的每一步都走进自己设计的剧本。
- **结果**：桂陵、马陵两战，庞涓在马陵道看到"庞涓死于此树之下"的字样、火把亮起万弩齐发；「庞涓自知智虑穷尽而败局已定，这才自杀，说：终究成就了这小子的名声！」孙膑名显天下。
- **显性代价**：双足与面容（膑刑＋黥刑）——永久不可逆；十余年蛰伏。
- **隐性代价**：复仇叙事也定义了孙膑的后半生；他的军事艺术里处处是"诱敌入设定"的印记——受过的伤会塑造方法，方法是武器也是限制。
- **规律启发**：①才华在熟人圈里最先触发的是同侪恐惧，而非欣赏，"同门相残"往往源于对方的能力焦虑；②绝境自保律：当无法正面对抗时，让自己"不值得杀"（价值低-威胁低）；③复仇的正确姿势不是情绪爆发，而是把对方引入你的系统（减灶诱敌的是博弈设计，不是愤怒）。
- **风险提醒**：此案例容易被读成"忍辱—复仇"爽文模板。真实前提是：孙膑有齐使愿冒风险救他（外部选项的存在）。评估自己时先问："我的'齐国'在哪里？"没有外部出口时，忍的意义完全不同。
- **原文**：「庞涓恐怕他比自己贤能,嫉妒他,便假借罪名施刑断去孙膑的双足并给他脸上刺字。」「孙膑估计庞涓的行程,当天日暮当到达马陵。」（《史记·孙子吴起列传》）
