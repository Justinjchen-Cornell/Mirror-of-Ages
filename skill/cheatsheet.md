# cheatsheet.md — 抉择速查卡（单人单页）

## 决策规则（When X → Do Y, because Z）

| 触发场景 | 动作 | 依据 |
|---|---|---|
| 功劳/能力显著高于上级容忍度 | 主动拆"威胁属性"（交权、透明、小尺度化诉求），少做忠诚声明 | 王翦/萧何/郭子仪（卷七、十二、二二四） |
| 面临"该不该退" | 检查原始目标是否已完成；退出要带身份转换+不给对方留"你会回来"的疑虑 | 范雎/张良/疏广（卷六、十一、二五） |
| 对方开出的承诺里有"你先动"条款 | 校验其"履约剩余动机"；要担保/第三方/可执行罚则 | 张仪欺楚（卷三） |
| 对方有碾压优势且情绪化 | 第一动作=降低威胁感；脱身窗口出现立刻走；留善后牌 | 鸿门宴（卷九） |
| 合伙人间出现"他当时没救我"心结 | 先假定约束条件再判断动机；绝不用"退出/散伙"表达委屈 | 张耳陈馀（史记） |
| 选择老板/平台 | 看三点：决策机制、利益分配结构、长期路线（你认不认同终点） | 荀彧择主（卷六十） |
| 团队出现集群性动摇（通敌/摸鱼潮） | 打击最小集（主谋），安抚最大集（从众），一次动作完成 | 曹操焚书/刘秀烧谤书（卷六三、三九） |
| 接班人/交接对象不合格 | 冗长试探不如"条件清单+程序+见证人"；必选好替代方案再动手 | 霍光废立（卷二十四） |
| 组织出现"反对者消失"现象 | 视为最高风险信号；主动制造反对意见渠道 | 苻坚淝水（卷一〇四） |
| 事前反对、事后证明正确的人 | 公开承认其正确性——这是组织纠错能力的标尺 | 袁绍杀田丰反例（卷六三） |
| 新人接任前任 | 先判断前任遗产是资产还是负债；说不清"非改不可的原因"就不动 | 萧规曹随（卷十二） |
| 长期逆境/被边缘化 | ①活下去②保持单一核心资产不贬值③等结构变化；设再评估点 | 苏武（卷二三） |
| 受辱当口 | 算"一生的账"；在冲动与行动之间插入一次成本核算 | 韩信胯下（史记） |
| 想给后代留财产 | 排序：能自立的习惯>可倚靠的关系>不可夺走的资产（名声学识）>钱 | 疏广/萧何/杨震（卷二五、十二、四九） |
| 教育子女选榜样 | 选"失败下限高"的榜样（刻鹄尚类鹜），慎选"上限高下限危险"的（画虎反类狗） | 马援诫侄（卷四四） |
| 被诬陷/名誉危机 | 主动透明+即时应答+留证据；清者自清是低效策略 | 郭子仪/马援薏苡（卷二二四、四四） |
| 弱方谈判 | ①先定义是非归属②找对手长期成本③用自己的"无所谓"换对方"有所谓" | 蔺相如（卷四） |
| 重大豪赌前 | 拆对方优势为"本场景有效/无效"清单；写"永远不做什么"的备忘录 | 周瑜拆曹操/王猛遗言（卷六五、一〇三） |

## 反模式速查（历史翻车清单）

- **杀信使**：处置"事前反对、事后正确"的人（袁绍→田丰）→ 信息管道关闭
- **换将式立威**：接任即推翻前任全部路线（赵括/李信）→ 大败
- **全押式自信**：把过往成功经验平移到新场景（苻坚伐晋）→ 帝国解体
- **赌气退场**：用辞职/散伙表达委屈（陈馀解印绶）→ 关系彻底破裂
- **情感式结盟**：把对方动机当履约担保（楚怀王信张仪）→ 被反复收割
- **身后无证据**：清白但说不清（马援薏苡）→ 身后被诬
- **只示忠不拆雷**：忠诚声明代替结构行动（檀道济）→ 存在即威胁
